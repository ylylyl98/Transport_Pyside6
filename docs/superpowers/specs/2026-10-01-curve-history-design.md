# Measurement history and curve comparison

Approved scope: the conversation requests a current-folder history browser for comparing scans. User refinements require all dates newest first, separate history pages per measurement type, 2D map viewing followed by measured-coordinate cuts, and protecting measurement responsiveness. The Curve Compare tab therefore launches a single independent read-only viewer process. Reopening the window restores choices; viewer exit/failure leaves acquisition running.

The default root is the current operator/device directory beneath the configured save base. Recursively discover date/type folders, default to All dates newest first, and separate Vds Sweep, Gate Scan, 2D Map, B-field Gate Scan, B-field Sweep and Photocurrent. Allow date filtering, text search and a custom folder. Display time, type, condition summary, filename and acquisition status. Newly completed measurements and opening the page trigger a refresh; a visible-page timer discovers external changes. Existing CSV/metadata remain authoritative and are never rewritten.

User's layout refinement: file selection uses a full-height left sidebar with multi-line entries, with plots on the right. A horizontal splitter allows manual width changes. Expand file list temporarily hides plots and grants the list the whole content area; Return to comparison restores widths, selections and already loaded plots.

Directory indexing reads metadata and CSV headers only, in cached background tasks inside the viewer. Read full CSVs only for checked curves; numeric snapshots have a 64 MiB cache. Preserve source point order, split directions and conditions, do not average duplicate coordinates or invent data. Native 2D map PassIndex is a slow-row identifier, not a repeated full scan; default to all rows and normalize reverse/backward markers. Exact measured fixed coordinates and primary-map units govern cuts. Report malformed files, missing axes/channels, partial trailing rows and incompatible units per file without blocking usable curves. Preserve checked paths/settings per directory/type through QSettings; invalidate async results only when the selected data or controls actually change.

Use Python 3.10+, PySide6 Qt Widgets, existing Matplotlib and NumPy dependencies, existing app styling and native window behavior. The viewer imports no hardware/control modules and runs below normal CPU priority. Its tab entry is excluded from measurement start/stop loops. IPC carries only folder/refresh/focus/close commands. No history parsing or rendering runs on the acquisition app's GUI thread. Acquisition/output formats stay unchanged. Hardware shutdown still completes before viewer shutdown. Shared disk/RAM mean this is process isolation, not a hard real-time guarantee. Validate with isolated settings and blocked instrument access.
